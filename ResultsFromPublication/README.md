# R code and result files

R code can be found in AnalysisAndFigure.Rmd

Result files generated in this study can be found in ResultFiles/.

Results using SPAdes assemblies and Unicycler assemblies as input for the plasmid tools are provided. Both runs produce MetricsAndTyping outputs although for specific metrics the results will be identical, specifically sequencing coverage, mash distances and kleborate output. These are identical as they use the hybrid genome assemblies. The output files are not date stamped when they produce the same results.

Number of IS elements on plasmids was taken from [Winkler et al.](https://doi.org/10.1099/mgen.0.001629) and is not provided here. The data can be found in supplementary table 1 which can be downloaded from [supplementary material 2](https://www.microbiologyresearch.org/content/journal/mgen/10.1099/mgen.0.001629#supplementary_data).
